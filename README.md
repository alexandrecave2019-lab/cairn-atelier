# CAIRN Atelier parcours

Atelier de parcours de l'application d'entraînement trail CAIRN :
boucles calées sur les séances, recherche de côtes, tracé à la main,
tronçons de la course et export GPX vers Garmin Connect.

Site : https://alexandrecave2019-lab.github.io/cairn-atelier/

Données : Géoplateforme IGN (itinéraire piéton, altitude, recherche de lieux),
OpenRouteService hors de France (clé personnelle), fonds IGN et OpenTopoMap.
Carte : Leaflet 1.9.4 (BSD-2).

Les sources sont sur la branche `source`.
